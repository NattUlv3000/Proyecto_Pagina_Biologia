# Biología Interactiva

Página web interactiva sobre biología y naturaleza.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Información sobre animales.
- Investigaciones de biología.
- Registro de usuarios.
- Inicio de sesión.
- Interacciones mediante JavaScript.
- Buscador y filtros de animales.
- Quiz de biología.
